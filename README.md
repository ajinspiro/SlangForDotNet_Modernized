# SlangForDotNet Compiler/Interpreter

> तेजस्वि नावधीतमस्तु — _May what we study become radiant and illuminating for both of us (teacher and student)._

## About

**SlangForDotNet** is an educational compiler and interpreter project designed to teach the fundamentals of compiler/interpreter/DSL construction. This modernized version targets **.NET 10** and builds upon the original work by Praseed Pai K. T.

**Note:** This is an educational project and not intended for production use.

## Project History

- **Original Creator:** [Praseed Pai K. T.](https://www.linkedin.com/in/praseed-pai-k-t-369ba225/)
- **Original Version:** [Targets .NET 3.5](https://github.com/praseedpai/SlangForDotNet/)
- **Modernized Version:** .NET 10
